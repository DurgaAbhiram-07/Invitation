# Invitation

An elegant single-page web invitation for a maturity ceremony, featuring animated opening, countdown timer, RSVP modal, and background music.

## Preview

Open [invitation.html](invitation.html) in any modern browser.

## Features

- Animated welcome screen with confetti and floating petals
- Event details card with countdown timer
- Blessings section and event timeline
- RSVP modal (client-side only)
- Music toggle with background audio
- Responsive layout and decorative styling

## Customize

Edit [invitation.html](invitation.html) and update:

- Event title, date, time, and venue in the details box
- Countdown date in the script (`eventDate`)
- Family name and closing message
- Header image (`pranavi.png`) used in the circular avatar
- Background music URL in the audio source

## Tech

- HTML, CSS, JavaScript
- Google Fonts (Great Vibes, Playfair Display, Poppins)
- Font Awesome icons
- canvas-confetti for celebration effects

## Notes

- RSVP is a demo flow and logs to the console; no backend is wired up.
- This project is static and does not require any build step.
